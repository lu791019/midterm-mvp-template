ELT vs ETL — 你今天做的是 ELT

傳統 ETL：先轉換再載入資料庫。現代 ELT：先把原始資料載入資料庫（Bronze 層），再在資料庫內做轉換。 好處是保留原始資料可回溯、轉換邏輯用 SQL 管理、符合 Snowflake / BigQuery / Databricks 的主流架構。

Modern Data Stack 對照

Ingestion→ 你的 pd.read_csv()（業界：Fivetran / Airbyte）
Storage→ 你的 SQLite（業界：Snowflake / BigQuery）
Transform→ 你的 pandas + SQL（業界：dbt）
AI/ML→ 你的 LLM API（業界：SageMaker / Vertex AI）
Serving→ 你的 FastAPI + Streamlit（業界：Looker / Metabase）
