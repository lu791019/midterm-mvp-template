循序漸進：前面手把手 → 後面放手

Section 1：Extract

CSV 檔案 → pd.read_csv() → DataFrame → df.to_sql() → SQLite raw 表

為什麼寫入資料庫？

  • 真實 DE 工作中，資料不會一直是 CSV
  • 寫入 DB → 可 SQL 查詢 → 可被 API 存取
  • 今天用 SQLite（零安裝），後續升級到 MySQL / BigQuery

Section 2：Transform

問題怎麼處理pandas
缺漏值刪掉或填值df.dropna()
型別錯字串轉數字pd.to_numeric()
日期字串轉 datetimepd.to_datetime()
異常值過濾掉df = df[df["col"] > 0]

Prompt 設計技巧

1. 給明確標籤
❌ 「請分析」 → ✅ 「分類為：家飾/禮品/餐具/季節商品/文具/其他」
2. 要求 JSON 回傳
✅ {"category": "...", "insight": "..."}
3. 加上「不確定就選最接近的」
避免 LLM 拒答

API vs Fallback

有 API Key

llm_analyze(text, api_key)

呼叫 GPT-4o-mini

沒有 API Key

llm_analyze(text, None)

用關鍵字規則判斷

兩個都能完成。沒 Key 不影響完成度。
