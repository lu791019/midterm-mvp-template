🏭 業界概念：DE 在組織中的位置

為什麼 DE 是「顧問」

  • 📋 懂業務：把需求翻譯成技術規格
  • 🔧 有技術：Python / SQL / API 落地
  • 🏗️ 建架構：ETL + 資料庫分層 + API
  • 🤝 能導入：從原型到部署

DE vs DA vs DS

DE 資料工程師建管線、管資料流、維護架構
DA 資料分析師分析資料、做報表、回答問題
DS 資料科學家建模型、做預測、設計演算法

今天你同時體驗三者：建管線(DE) + 做統計(DA) + 用 LLM(DS)

🏭 業界概念：LLM in Data Pipeline

Structured Output

LLM 回傳 JSON → 直接存進資料庫欄位

{"category": "家飾", "insight": "..."}

不是自由文字，是固定結構 → 可程式化處理

LLM FinOps（成本意識）

GPT-4o-mini：~$0.15 / 1M input tokens

2,000 筆 × ~100 tokens ≈ $0.03

業界做法：先跑 fallback baseline → API 加值比較效果

📋 Prompt 設計 + API vs Fallback

Prompt 三原則

1. 給明確標籤選項

2. 要求 JSON 回傳

3. 加「不確定就選最接近的」

範本：docs/ai_prompts.md

API vs Fallback

有 Key → 呼叫 GPT-4o-mini

沒 Key → 關鍵字規則判斷

兩個都能完成

流程：1 筆測試 → 確認 → 批次 50 筆 → 寫入 Gold
