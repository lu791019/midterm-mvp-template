## 講師回饋模板

每組報告後，用以下結構給回饋（2-3 分鐘）：

1. **肯定**：「你們的 _____ 做得很好」
2. **建議**：「如果能再 _____，會更完整」
3. **連結下午**：「下午實作的時候，可以把 _____ 的想法先用 MVP 驗證」

---

## 常見回饋句型

| 情境 | 回饋 |
|------|------|
| 問題太大 | 「先縮小範圍，期末再擴展。今天下午可以先做其中一個子問題的 MVP」 |
| 沒有資料 | 「先用公開資料集驗證流程，之後再換真實資料」 |
| 架構太複雜 | 「期末再加 Airflow/Docker，先把 CSV → SQLite → API 跑通」 |
| 分工不均 | 「建議每個人都碰到 pipeline 的至少兩個階段，不要只做一段」 |
| 報告太散 | 「下次用 問題→資料→架構→分工 的結構，聽眾更容易跟上」 |
