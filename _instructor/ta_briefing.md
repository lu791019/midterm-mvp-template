## 巡場 SOP

### 什麼時候介入

| 訊號 | 行動 |
|------|------|
| 盯著螢幕不動超過 3 分鐘 | 走過去問「卡在哪？」 |
| 一直在 Google 搜尋 | 問「你在找什麼？Notebook 裡有沒有提示？」 |
| 表情困惑但不舉手 | 主動靠近問「需要幫忙嗎？」 |

| 整組都卡住 | 叫講師過來，可能是共同問題 |

### 什麼時候不介入

- 正在打字、有在動 → 讓他做
- 在跟組員討論 → 讓他們聊
- 在用 ChatGPT → 正常，讓他用

### 巡場節奏

每 10 分鐘走完一圈（3 組），重點觀察：

| 時間點 | 觀察什麼 |
|--------|---------|
| T+5 min | 有沒有人還沒開 Notebook？ |

## 常見問題 QA

### 環境類

| 問題 | 回答 |
|------|------|
| Colab 打不開 | 「用本地 Jupyter：`pip install jupyter && jupyter notebook`」 |
| `pip install` 失敗 | 「Colab 已經內建 pandas，不用裝。如果本地的話試 `pip3`」 |
| CSV 讀不到 / FileNotFoundError | 「用 `os.getcwd()` 看你在哪個資料夾。CSV 要跟 Notebook 在同一層」 |
| `import sqlite3` 出錯 | 不會出錯，Python 內建。可能是打錯字 |

### 程式碼類

| 問題 | 回答 |
|------|------|
| `KeyError: 'xxx'` | 「用 `df.columns` 看一下實際的欄位名稱，大小寫有差」 |
| `dropna` 刪光了 | 「可能 subset 寫錯欄位。用 `df.isnull().sum()` 看哪些欄位有缺」 |
| SQL 語法錯 | 「GROUP BY 後面要放 SELECT 裡非聚合的欄位」 |
| `to_sql` 覆蓋舊資料 | 「正常，`if_exists='replace'` 就是會覆蓋」 |
| 題 4 merge 失敗 | 「兩張表的 key 欄位名不同？用 `left_on='PULocationID', right_on='LocationID'`」 |
| 題 6 民國年 | 「交易年月日前 3 碼 + 1911 就是西元年」 |

### LLM 類

| 問題 | 回答 |
|------|------|
| 沒有 API Key | 「沒關係，用 fallback 版（Notebook 裡有）。fallback 用關鍵字規則，不需要 API」 |
| API 回 error | 「先切到 fallback 把流程跑通，API 之後再接」 |
| JSON 解析失敗 | 「Prompt 裡加一句：『請只回傳 JSON，不要加其他文字』」 |
| 跑太慢 | 「改 BATCH_SIZE 成 20 先看結果，不用等 50 筆全跑完」 |

### FastAPI 類

| 問題 | 回答 |
|------|------|
| `uvicorn` 找不到 | 「`pip install uvicorn fastapi`」 |
| API 回 500 | 「確認 pipeline.db 存在，要先跑完 Notebook 的 Section 1-4」 |
| Colab 跑不了 FastAPI | 「Notebook Section 8 有用 threading + nest_asyncio 的方法」 |

### 心態類

| 「我做不完」 | 「完成到哪就 Demo 到哪，沒有人會全部做完」 |
