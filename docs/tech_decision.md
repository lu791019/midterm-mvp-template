# Tech Decision

| Decision | Choice | Why |
|---|---|---|
| Language | Python | 課程主工具，適合資料處理 |
| Data processing | pandas | 快速完成 MVP 清洗與統計 |
| Storage | CSV | 期中先求能跑，之後升級 DB |
| AI analysis | fallback rules / LLM API | 先保證能跑，再接真實 API |
| Dashboard | Streamlit | 快速做可展示介面 |
| Container | Docker template | 後續 Docker 課程升級 |
